# ADR-028：V2.4 项目经验与受控 AI / V2.4 Project Experience and Controlled AI

- 状态：已接受（D133-A–D142-A） / Status: Accepted (D133-A–D142-A)
- 日期：2026-10-11 / Date: 2026-10-11
- 依据：[V2.4 决策门](../application/PIG-V2.4-decision-gate.md)及负责人本次确认 / Basis: [V2.4 gate](../application/PIG-V2.4-decision-gate.md) and the owner's confirmation
- 当前实施与验收状态以 [CURRENT_SCOPE](../project-rules/CURRENT_SCOPE.md) 为准 / Implementation and acceptance status follow [CURRENT_SCOPE](../project-rules/CURRENT_SCOPE.md)

## 决定 / Decision

1. **D133-A、D141-A**：先完成人工经验闭环。`ProjectExperienceRecord` 与显式关系
   保存判断、决定和经验及其作者、状态、修改历史和固定 Revision 依据；已有 Event 只
   表达观察到的操作，Item Annotation 仍表达文件阅读说明。不得把 AI 草稿当作人工事实。
2. **D142-A**：扩展 Context Pack 为版本化、机器可读的 Context Bundle，并提供语义一致
   的只读 Application Query Contract。先用合成消费者验证；不在 V2.4 建真实平台
   Adapter、HTTP/MCP Server、OAuth、Webhook、双向同步或外部写入。
3. **D134-A、D139-A**：使用用户自备凭据的远程模型 API，通过一个可替换 Provider
   Port 接入。先验收一个真实 Adapter，再资格评估第二个；V2.4 完成时用户可以在至少
   两个合格 Provider 的模型之间切换。具体 Provider、模型、条款、数据保留和费用参数
   在首次真实外发前单独核验，本 ADR 不批准具体服务或业务资料试传。
4. **D135-A、D136-A**：每次远程请求展示确定输入计划并一次性确认；输入、Provider
   或模型变化使确认失效。长内容采用有界、可预览的元素集合，缺失范围标明
   `PARTIAL_INPUT`，不得伪称全文覆盖。
5. **D137-A、D138-A**：结构化 AI 草稿中的每项实质陈述必须带本次输入内有效引用；
   错误引用不能标为成功。项目内保存草稿、引用、输入版本、Prompt/模型版本、状态及
   最少必要用量，不保存 Secret、完整外发 Payload 或 Debug 正文。草稿默认保留至用户
   显式清理；被引用者不得静默移除。
6. **D140-A**：延续简洁桌面布局。文件说明与关联判断位于核心文件附近，跨文件人工
   经验以克制的“项目脉络”列表呈现；AI Action 在选定固定 Revision 旁按需展开，
   不建立自由聊天主页。

1. **D133-A, D141-A**: Complete the human-experience loop first. Explicit links connect
   judgment, decision, and lesson records to fixed Revision evidence with authorship, status,
   and edit history. Events remain observed actions, Item Annotations remain reading guidance,
   and AI drafts never become human facts implicitly.
2. **D142-A**: Extend Context Pack into a versioned machine-readable Context Bundle with
   semantically aligned read-only Application Queries. Verify a synthetic consumer first; no
   real vendor adapter, HTTP/MCP server, OAuth, webhook, two-way sync, or external write in V2.4.
3. **D134-A, D139-A**: Use user-supplied credentials for remote model APIs through one
   replaceable provider port. Accept one real adapter before qualifying a second; V2.4 completion
   includes switching between models from at least two qualified providers. Qualify actual
   services, models, terms, retention, and cost before real transmission; this ADR approves none.
4. **D135-A, D136-A**: Preview and confirm each remote request. Changed inputs, provider, or
   model invalidate consent. Bound and preview long-input element selection, mark omitted coverage
   as `PARTIAL_INPUT`, and never claim full-document coverage falsely.
5. **D137-A, D138-A**: Every material structured claim needs a valid citation within that
   request's inputs; invalid citations cannot succeed. Persist drafts, citations, input versions,
   prompt/model versions, state, and minimal usage without secrets, full outbound payloads, or
   debug text. Retain drafts until explicit cleanup and protect referenced drafts.
6. **D140-A**: Keep the compact desktop UI. Show file guidance and linked judgments near core
   files, cross-file records in a restrained Project Journey list, and AI Actions on demand next
   to selected fixed Revisions; no free-chat home page.

## 边界与后果 / Boundaries and consequences

人工记录由人明确提供，PIG 不声称捕获外部 Host Application 的每次保存或人的隐性思考。
模型不修改 Workspace、Context、数据库或外部系统。Project Context、Pack、人工记录与
本地搜索在无凭据、无网络时继续可用。AI 只消费用户明确选择且可校验的固定 Revision；
PDF/DOCX/PPTX 解析器与真实资料外发仍受各自独立 Gate 约束。V2.4 的经验记录不提前
实现 V2.5 的结构化时间线、决定关系图和多视图投影。

Human records are explicitly authored; PIG cannot claim to observe every external-host save or
unspoken thought. Models cannot modify Workspace, Context, the database, or external systems.
Project Context, Pack, human records, and local search remain usable without credentials or
network. AI consumes only explicitly selected, verifiable fixed Revisions. PDF/DOCX/PPTX parser
qualification and real-data transmission retain separate gates. V2.4 records do not pre-build
V2.5's structured timeline, decision graph, or multiple projections.
