# ADR-032：V2.4 本机合成 DeepSeek 外发范围 / V2.4 Local Synthetic DeepSeek Egress Scope

- 状态：已接受 / Status: Accepted
- 日期：2026-10-16 / Date: 2026-10-16
- 依据：负责人决定仅完成 DeepSeek 资格，不处理 OpenAI 401，暂缓真实 API 异常与桌面闭环验收，并选择本机源码桌面、仅合成资料的方案 A。当前实施与签收状态见 [CURRENT_SCOPE](../project-rules/CURRENT_SCOPE.md)。
- Basis: The owner chose DeepSeek-only qualification, deferred OpenAI 401 and live-API failure/desktop-loop acceptance, and selected option A: local source desktop with synthetic material only. See [CURRENT_SCOPE](../project-rules/CURRENT_SCOPE.md) for implementation and acceptance status.

## 决定 / Decision

1. V2.4 的当前受限试运行不再以两个 Provider 合格为前提。OpenAI 仍可保留代码，但不得在该运行入口发起外发；这只取代 [ADR-029](ADR-029-v2.4-provider-and-budget-gate.md) 的双 Provider 当前验收顺序，不宣称 OpenAI 已通过资格。
2. 只有本机**源码桌面**可以为 DeepSeek 开启受限外发。打包运行、其他启动入口、其他 Project、其他 Action/模型及输入变化均不得外发；缺少指定合成项目时关闭。当前唯一许可为已验证合成项目的固定 Revision 摘要及其输入指纹。UI 的许可提示不能替代后端检查。
3. 每次外发仍展示精确输入、Provider/模型、覆盖范围和费用估算，并需人工点击确认；确认令牌一次有效。保留单次 US$0.50 估算和合成活动 US$5 估算预算，无自动重试、无真实业务资料外发。
4. 真实 API 异常/取消/超时、打包桌面闭环、账号级条款与留存以及真实项目资料外发均未由本次方案 A 签收。不得把受限合成试运行表述为正式打包版生产发布。扩大范围时须重新作明确决定与验证。

1. The current bounded V2.4 trial no longer requires two qualified providers. OpenAI code may remain, but that runtime entry cannot send through it. This supersedes only ADR-029's two-provider current acceptance sequence; it does not qualify OpenAI.
2. Only the **local source desktop** may enable bounded DeepSeek egress. Packaged runs, other launch paths, other Projects, other Actions/models, or changed input cannot transmit. Missing the specified synthetic Project disables the gate. The sole approved input is the verified fixed-Revision summary and its fingerprint. UI messaging cannot replace backend enforcement.
3. Every send still previews exact text, provider/model, coverage, and estimate and requires the user to click confirmation. The token is one-shot. Retain the US$0.50 estimated per-request and US$5 estimated synthetic-exercise limits, with no automatic retry or real business-data transmission.
4. Live failure/cancellation/timeout, packaged-desktop flow, account-specific terms/retention, and real Project material are not signed off by option A. Do not present this bounded synthetic trial as a formally released packaged production capability. Scope expansion requires a new explicit decision and verification.

## 实施边界 / Implementation boundary

当前本机许可绑定项目 ID、规范化数据库路径和计划 Fingerprint。Fingerprint 含 Action、Provider、模型、Prompt 版本、输入元素身份、Locator 与文本摘要；后端在发送前重新计划，变化即拒绝。打包检测在组合入口再次拒绝开启，即使调用方传入试运行参数。许可项目不随应用分发，其他机器没有该项目时默认关闭。

The local allowance binds the Project ID, resolved database path, and plan fingerprint. The fingerprint covers Action, provider, model, prompt version, element identities, locators, and text hashes. The backend rebuilds the plan before sending and rejects changes. Packaged detection denies enabling the trial even if the caller passes its flag. The approved Project is not distributed; absence on another machine leaves egress disabled.
